## 4. 主要发现

### 4.1 LoRA 确实学到了角色对话分布

六个 LoRA 的 PPL 均约为 9.4 至 11.1，而 `Base + card` 通常约为 94 至 177。
这证明训练有效改变了模型对角色回复的概率分布。

但 `train_2` 同时具有最低 PPL、最高重复率和最低多轮分数，因此 PPL 不能作为
角色一致性的单一指标。

### 4.2 角色卡 Prompting 是强基线

以 `train_4` 为例：

- 单轮：`Base + card` 比 `Base, no card` 高 0.765；
- 多轮：`Base + card` 比 `Base, no card` 高 1.270。

角色卡本身带来的收益大于当前 LoRA 在其上的额外单轮增益。

### 4.3 较长上下文有利于单轮角色表现

`train_3` 相比 `train_2` 将上下文从 512 增至 1024，Identity 从 2.657
提高到 2.970，单轮胜率从 48.6% 提高到 55.6%，多轮综合也从 2.225
恢复到 2.890。

由于两次训练的数据哈希和 Judge 有效样本量不同，这只能写成相关趋势，不能写成
严格单变量因果结论。

### 4.4 降低学习率缓解重复，但未修复多轮退化

`train_4` 相比 `train_3`：

- Distinct-1：0.652 -> 0.718；
- Distinct-2：0.761 -> 0.809；
- 重复率：23.9% -> 18.1%；
- 单轮综合：2.935 -> 2.938；
- 多轮综合：2.890 -> 2.668。

较温和的优化提高了生成多样性，但第二轮验证 loss 略升，多轮表现没有改善。

### 4.5 数据清洗改善有限，未解决多轮退化

`train_5` 的单轮综合达到 2.989，是当前最高值；重复率 17.8%，也略低于
`train_4` 的 18.1%。但它对 `Base + card` 的单轮配对差异仍不显著
（95% CI 为 [-0.039, 0.580]），多轮综合为 2.780，明显低于同次评估中
`Base + card` 的 3.523。

复现性上，`train_5` 清单记录 `data_dir=processed_clean`，但 train/val/test
hash 与当前 `processed/` 一致、与当前本地 `processed_clean/` 不一致。因此它
应作为一次清洗目录运行结果记录，而不是严格的清洗单变量因果证据。

因此，过滤重复回复样本可以改善单轮表面质量，但不足以让 LoRA 学会多轮对话中
稳定保持身份、风格和沉浸感。

### 4.6 多轮窗口训练没有修复多轮退化

`train_6` 改用 assistant turn 多窗口样本，验证损失降至 2.258，低于
`train_5` 的 2.299；但评估质量没有同步提升：

- 单轮综合：`train_5` 2.989 -> `train_6` 2.921；
- 单轮胜率 vs `Base + card`：55.0% -> 50.0%；
- 多轮综合：两者均为 2.780；
- 多轮 memory：3.600 -> 3.700；
- 多轮 identity：2.600 -> 2.550；
- 多轮胜率 vs `Base + card`：25.0% -> 20.0%。

因此，多窗口监督可能略微增强了记忆维度，但没有改善身份、连贯性、风格和总体
多轮角色保持。它还进一步说明 eval loss 低不等于角色扮演质量更高。

### 4.7 重复生成是最明确的质量缺口

`train_6` 是重复率最低的 LoRA，但 17.3% 仍约为 `Base + card` 2.9% 的
6.0 倍。代表失败案例会出现动作、感谢句式或固定承诺的循环生成。

| 实验 | 有效单轮 Judge | 多轮 | Judge 成功率 | 顺序一致性 |
|---|---:|---:|---:|---:|
| `train_1` | 100 | 20 | 100% | 85.7% |
| `train_2` | 70 | 20 | 100% | 76.9% |
| `train_3` | 99 | 20 | 99.2% | 50.0% |
| `train_4` | 99 | 20 | 99.2% | 92.9% |
| `train_5` | 100 | 20 | 100% | 64.3% |
| `train_6` | 100 | 20 | 100% | 57.1% |

`train_3` 的顺序一致性只有 50%，因此其单轮改善趋势需要复测；`train_4`
的一致性较高，但单轮 CI 仍包含 0。

## 6. 可直接用于论文的结论

### 有证据支持

- QLoRA 可以在消费级 GPU 上完成 3B 模型角色对话适配。
- LoRA 显著降低 assistant reference PPL。
- 角色卡 Prompting 对单轮和多轮角色扮演都有明确收益。
- 1024 上下文配置呈现更好的单轮角色表现趋势。
- 较低学习率和最佳 checkpoint 选择降低了重复率。
- 当前六个 LoRA 模型的多轮综合表现均低于 `Base + card`。
- 多轮窗口训练没有解决多轮综合退化，只带来 memory 维度的小幅提升。

### 不应直接声称

- “LoRA 显著超过 Base + card”：单轮 CI 均包含 0。
- “角色分组已经消除数据泄漏”：当前磁盘数据未通过角色名跨 split 审计。
- “train_3 的提升完全来自上下文长度”：训练数据快照不同。
- “17.3% 重复率已经接近基线”：它仍显著高于 2.9%。
- “清洗重复数据或多轮窗口训练能解决多轮一致性”：`train_5/train_6` 没有支持该结论。

## 7. 后续优先级

1. 固定并版本化同一数据快照，重新运行严格单变量消融。
2. 修复角色分组键并加入跨 split 角色重叠测试。
3. 继续改进多轮训练目标，例如增加历史一致性偏好数据或显式反重复样本。
4. 增加人工盲评或第二 Judge，降低单一裁判和顺序偏差。
5. 允许 Judge 输出平局，并扩大多轮角色数。
6. 在统一数据上再比较学习率、rank 和 FFN target modules。
