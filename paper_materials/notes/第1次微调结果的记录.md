## 核心结论

这次 LoRA **学到了训练数据的表达模式，但没有稳定提升整体角色扮演能力**。

与 `Base + card` 相比：

- 单轮综合分：`2.675 → 2.718`，仅提升 `0.043`
- 单轮胜率：LoRA 只有 `44%`，Base + card 是 `56%`
- 多轮综合分：`3.448 → 2.763`，明显下降
- PPL：`94.725 → 10.404`，大幅下降
- 重复率：`0.029 → 0.256`，严重升高
- 生成速度：`25.542 → 17.705 tokens/s`

所以不能只根据 PPL 判断 LoRA 效果很好。

## 指标解释

### PPL

PPL 越低，表示模型越熟悉测试文本的语言模式。

LoRA 的 PPL 从 `94.725` 降到 `10.404`，说明微调确实生效了。但 PPL 低不等于角色扮演质量高，也可能表示模型过度学习了训练集中的固定句式。

而且 `Base, no card` 的平均 PPL 为 `872.614`、中位数只有约 `29.96`，说明平均值受到少数极端样本影响，不能单独比较平均值。

### Fidelity / Identity

表示是否符合角色身份和人设。

- Base + card：`2.480`
- LoRA + card：`2.770`

这是 LoRA 最明确的正面效果：**单轮角色身份表现有所提升**。

### Style

表示说话风格是否符合角色。

- Base + card：`2.670`
- LoRA + card：`2.560`

LoRA 反而稍差，说明它可能学到了通用角色扮演格式，而不是每个角色独特的语言风格。

### Memory

表示多轮对话中能否记住前文信息。

- Base + card：`3.200`
- LoRA + card：`3.800`

LoRA 的记忆分数更高，但多轮连贯性和角色表现下降，因此可能属于“记得信息，但回答质量不好”。

### Distinct-1 / Distinct-2

衡量词语和词组多样性，越高越好。

LoRA：

- Distinct-1：`0.794 → 0.640`
- Distinct-2：`0.971 → 0.734`

说明生成内容明显变得更加模板化。

### Repetition

重复率越低越好。

LoRA 从 `2.9%` 上升到 `25.6%`，这是非常明显的问题。报告中的失败案例连续重复三次“令人兴奋”，就是该现象的具体表现。

## 最终判断

这次训练可以总结为：

> LoRA 微调成功降低了 PPL，并略微提升单轮角色身份匹配度和多轮记忆能力；但同时导致严重重复、表达多样性下降以及多轮连贯性和角色沉浸感退化。当前 LoRA 总体没有超过直接使用角色卡的基础模型，可能存在过拟合或训练数据模板化问题。
