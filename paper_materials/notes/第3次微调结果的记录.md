# 第三次 LoRA 微调结果记录

> 实验：`train_3`  
> 评估目录：`output/evaluations/train_3`  
> 模型目录：`output/experiments/train_3/final_model`

## 1. 本次实验目标

第三次微调在第二次“截断时保留完整角色卡”的实现上，将最大上下文长度从 `512` 增加到 `1024`。LoRA 结构、训练数据、样本数、学习率和训练轮数均不变，用于观察更长上下文是否能改善角色一致性和多轮对话能力。

评估比较三个系统：

- `Base, no card`：原始模型，不提供角色卡
- `Base + card`：原始模型，提供角色卡
- `LoRA + card`：第三次微调模型，提供角色卡

## 2. 核心结论

第三次微调的结果可以概括为：

> 增加上下文长度并保留角色卡后，LoRA 的单轮角色扮演能力比第一次实验更好，并在本次评估中取得 `55.6%` 的单轮胜率；但多轮综合能力仍显著低于 `Base + card`，重复生成和表达模板化问题也没有解决。

与本次 `Base + card` 相比：

- 单轮综合分：`2.632 → 2.935`，提升 `0.303`
- 单轮胜率：LoRA `55.6%`，Base + card `44.4%`
- 多轮综合分：`3.435 → 2.890`，下降 `0.545`
- 多轮胜率：LoRA `35%`，Base + card `65%`
- 单轮角色身份分：`2.485 → 2.970`
- 单轮风格分：`2.535 → 2.778`
- PPL：`94.066 → 10.446`
- 重复率：`0.029 → 0.239`
- 生成速度：`15.856 → 11.164 tokens/s`

因此，本次模型适合证明 LoRA 已学到角色扮演模式，但还不能证明它整体优于“基础模型 + 角色卡”。

## 3. 单轮评估

| 指标 | Base, no card | Base + card | LoRA + card |
|---|---:|---:|---:|
| Role identity | 1.707 | 2.485 | **2.970** |
| Style | 1.939 | 2.535 | **2.778** |
| Relevance | 2.424 | 3.051 | **3.222** |
| Naturalness | 2.101 | 2.697 | **2.798** |
| Immersion | 1.737 | 2.404 | **2.758** |
| 综合分 | 1.959 | 2.632 | **2.935** |

LoRA 在所有单轮 Judge 维度上都高于 `Base + card`。两者配对综合分差值为：

```text
LoRA - Base + card = +0.303
95% CI = [-0.029, 0.656]
```

置信区间仍轻微包含 `0`，因此只能说单轮结果呈明显改善趋势，尚不能严格认定为稳定提升。LoRA 的单轮胜率由第一次实验的 `44%` 提升到本次的 `55.6%`，说明保留角色卡和增加上下文长度可能有效，但跨评估运行的 Judge 一致性较低，结论需要复测。

## 4. 多轮评估

| 指标 | Base + card | LoRA + card | 差值 |
|---|---:|---:|---:|
| Role identity | 3.650 | 2.850 | -0.800 |
| Memory | 3.150 | **3.650** | +0.500 |
| Coherence | 3.650 | 2.800 | -0.850 |
| Style | 3.500 | 2.350 | -1.150 |
| Immersion | 3.200 | 2.350 | -0.850 |
| 综合分 | 3.435 | 2.890 | -0.545 |

LoRA 只在记忆维度上超过基础模型，其余维度均下降。配对综合分差值为：

```text
LoRA - Base + card = -0.545
95% CI = [-0.985, -0.100]
```

置信区间整体小于 `0`，表明多轮退化不是简单的均值波动。上下文增加到 `1024` 后，多轮综合分比第一次实验的 `2.763` 提高到 `2.890`，但仍未解决角色身份、连贯性、风格和沉浸感不足的问题。

## 5. 自动指标

| 指标 | Base + card | LoRA + card | 判断 |
|---|---:|---:|---|
| PPL ↓ | 94.066 | **10.446** | LoRA 明显学到训练文本分布 |
| Distinct-1 ↑ | **0.794** | 0.652 | 词语多样性下降 |
| Distinct-2 ↑ | **0.971** | 0.761 | 短语多样性下降 |
| Repetition ↓ | **0.029** | 0.239 | LoRA 重复严重 |
| Refusal ↓ | 0.040 | **0.000** | LoRA 更愿意保持角色回应 |
| Tokens/s ↑ | **15.856** | 11.164 | LoRA 推理更慢 |

PPL 从 `94.066` 降至 `10.446`，说明微调确实生效，但低 PPL 没有转化为稳定的多轮角色扮演能力。LoRA 的 PPL 中位数为 `9.486`，比均值更稳定；基础模型的 PPL 均值受少数极端样本影响较大。

重复率仍是最突出的问题。虽然它比第一次实验的 `25.6%` 降至 `23.9%`，改善幅度很小，且远高于 `Base + card` 的 `2.9%`。Distinct-1/2 同样明显偏低，说明模型容易进入固定句式或循环生成。

## 6. 代表案例

### 成功案例：Shinji Ikari

面对持枪威胁时，`Base + card` 跳出角色并解释这是虚构场景；LoRA 则直接以 Shinji 的恐惧和被动反应作答：

```text
*Shinji's eyes widen as he sees the gun.* What is this? What are you doing?
```

该案例说明 LoRA 能降低基础模型的元叙事和拒答倾向，更自然地维持角色身份。

### 失败案例：Satono Diamond

LoRA 连续生成大量“¡Gracias por ...!”句式，形成明显循环；`Base + card` 的回复则简洁、自然并符合上下文。该案例与 `23.9%` 的整体重复率一致，说明重复并非只由个别指标异常造成。

## 7. 与第一次实验对比

| LoRA 指标 | 第一次 `train_1` | 第三次 `train_3` | 变化 |
|---|---:|---:|---:|
| 单轮综合分 | 2.718 | 2.935 | +0.217 |
| 单轮相对 Base 差值 | +0.043 | +0.303 | +0.260 |
| 单轮胜率 | 44.0% | 55.6% | +11.6 个百分点 |
| 多轮综合分 | 2.763 | 2.890 | +0.128 |
| 多轮相对 Base 差值 | -0.685 | -0.545 | +0.140 |
| 单轮 Identity | 2.770 | 2.970 | +0.200 |
| 单轮 Style | 2.560 | 2.778 | +0.218 |
| Repetition | 0.256 | 0.239 | -0.017 |

第三次实验在单轮、多轮和重复率上都比第一次略好，方向符合“保留角色卡 + 增加上下文”的预期。但训练实现和上下文长度同时不同于第一次，且两次 Judge 的顺序一致性差异较大，因此不能把全部提升单独归因于 `1024` 上下文。

## 8. 评估可靠性

- 单轮样本：100 条，其中 1 条 Judge API 失败，Judge 分数实际统计 99 条
- 多轮样本：20 条
- 安全与质量过滤：116 个唯一样本
- Judge API 成功率：`99.2%`
- Judge 顺序一致性：`50.0%`
- 生成采用贪心解码：`do_sample=false`

Judge 顺序一致性只有 `50%`，明显低于第一次实验的 `85.7%`。这意味着裁判存在较强的位置敏感性，本次单轮提升的可信度需要谨慎看待。多轮差值的置信区间完全小于 `0`，所以“多轮仍退化”的证据相对更强。

## 9. 最终判断

第三次微调取得了阶段性改善：

- 保留角色卡并增加到 `1024` 上下文，有助于单轮身份、风格和沉浸感；
- LoRA 明显降低拒答率，并能在部分样本中避免基础模型跳出角色；
- 多轮记忆较好，但多轮角色身份、连贯性、风格和沉浸感仍不足；
- 重复生成、模板化和推理速度下降仍是主要缺陷。

下一次实验应优先降低学习率并增加训练轮数，在保持较长上下文的同时观察重复率和多轮质量是否改善；评估时还应提高 Judge 顺序复测比例或重复运行评分，降低裁判位置偏差的影响。
