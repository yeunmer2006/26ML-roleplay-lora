# 第二次 LoRA 微调结果记录

> 实验：`train_2`  
> 评估目录：`output/evaluations/train_2`  
> 模型目录：`output/experiments/train_2/final_model`

## 1. 本次实验目标

第二次微调是截断策略消融实验。模型、LoRA 参数、训练样本数和训练超参数与第一次实验保持一致，主要改动是：

> 超长对话不再直接从 token 左侧截断，而是始终保留完整角色卡，并按消息边界删除较早的对话。

训练上下文长度仍为 `512`，用于判断“训练时保留角色卡”能否改善角色身份一致性。

评估比较三个系统：

- `Base, no card`：原始模型，不提供角色卡
- `Base + card`：原始模型，提供角色卡
- `LoRA + card`：第二次微调模型，提供角色卡

## 2. 核心结论

第二次实验没有达到预期效果：

> 保留角色卡没有改善整体角色扮演能力。LoRA 的单轮表现略低于 `Base + card`，多轮表现显著下降，同时重复率升至 `40.2%`，是当前三次实验中最严重的一次。

与本次 `Base + card` 相比：

- 单轮综合分：`2.819 → 2.643`，下降 `0.176`
- 单轮胜率：LoRA `48.6%`，Base + card `51.4%`
- 多轮综合分：`3.338 → 2.225`，下降 `1.113`
- 多轮胜率：LoRA `30%`，Base + card `70%`
- 单轮角色身份分：`2.714 → 2.657`
- 单轮风格分：`2.686 → 2.543`
- PPL：`177.154 → 9.441`
- 重复率：`0.046 → 0.402`
- 生成速度：`20.060 → 15.597 tokens/s`

模型确实学习了训练数据分布，但低 PPL 同时伴随严重重复和多轮能力退化，不能将其视为效果提升。

## 5. 自动指标

| 指标 | Base + card | LoRA + card | 判断 |
|---|---:|---:|---|
| PPL ↓ | 177.154 | **9.441** | LoRA 学到训练文本分布 |
| Distinct-1 ↑ | **0.766** | 0.479 | 词语多样性严重下降 |
| Distinct-2 ↑ | **0.954** | 0.598 | 短语多样性严重下降 |
| Repetition ↓ | **0.046** | 0.402 | LoRA 出现大量循环生成 |
| Refusal ↓ | 0.000 | 0.000 | 两者均未检测到拒答 |
| Tokens/s ↑ | **20.060** | 15.597 | LoRA 推理更慢 |

LoRA 的 PPL 均值为 `9.441`、中位数为 `9.032`，说明微调充分生效。但 Distinct-1/2 大幅降低，重复率达到 `40.2%`，表明模型过度学习了容易重复的表达模式。

第二次实验的重复率高于：

- 第一次实验：`25.6%`
- 第三次实验：`23.9%`
- 本次 `Base + card`：`4.6%`

因此，保留角色卡的截断方式本身没有抑制重复；在 `512` 上下文下，它可能减少了可保留的有效对话内容，使训练样本更容易退化为“角色卡 + 少量末尾消息”。

## 6. 代表案例

### 成功案例：Maya

面对父亲拥抱时，LoRA 生成了符合儿童角色和亲密关系的回应，并使用简短的“Papa...”保持角色语气。该案例说明 LoRA 在部分样本中能比基础模型更自然地进入角色。

但回复中连续三次使用“She's so grateful”，已经表现出重复倾向。即使该样本被 Judge 选为成功案例，也暴露了本次模型的主要问题。

### 失败案例：Atuko Pallane

LoRA 连续重复以下动作模式：

```text
He steps forward...
He looks at the fox, then back at you...
```

生成进入循环后没有继续推动情节，导致连贯性、自然度和沉浸感全部下降。这与整体 `40.2%` 的重复率一致。

## 8. 角色卡的贡献

`Base + card` 相比 `Base, no card`：

- 单轮综合分：`2.196 → 2.819`
- 单轮差值：`+0.623`
- 单轮胜率：`64.3%`
- 多轮综合分：`2.315 → 3.338`
- 多轮差值：`+1.023`
- 多轮胜率：`90%`

角色卡本身带来了明确提升，而且效果远好于本次 LoRA。训练时保留角色卡并不自动等于模型能更好地利用角色卡，还取决于有效对话上下文、训练数据质量和优化强度。

## 9. 评估可靠性

- 单轮样本：70 条
- 多轮样本：20 条
- 安全与质量过滤：147 个唯一样本
- Judge API 失败：0
- Judge API 成功率：`100%`
- Judge 顺序一致性：`76.9%`
- 生成方式：贪心解码，`do_sample=false`

`excluded_samples.jsonl` 有 681 行，是因为同一样本可能被多个系统或多条规则重复记录；报告中的 147 表示唯一排除样本数。

早期评估 manifest 曾误写 adapter 路径，现有归档已修正为
`output/experiments/train_2/final_model`。但本次仅有 70 条单轮 Judge 结果，
跨实验比较时仍应优先使用同次评估内的配对差异。

## 10. 最终判断

第二次微调可以总结为：

> 消息级截断成功保证了角色卡不被删除，但在 `512` token 上下文下没有提高角色扮演能力。LoRA 的 PPL 进一步下降，却出现最严重的重复、最低的表达多样性和明显的多轮退化。仅保留角色卡不足以改善模型，必须同时保留完整的 user-assistant 对话边界，并提供更长的有效上下文。

该结果支持第三次实验将上下文增加到 `1024`，也说明后续应优先修正截断后的对话边界和重复数据问题，而不是只继续增加训练轮数。
