# 第五次 LoRA 微调结果记录

> 实验：`train_5`  
> 评估目录：`output/evaluations/train_5`  
> 模型目录：`output/experiments/train_5/final_model`

## 1. 实验目标

第五次微调沿用 `train_4` 的 1024 上下文、`lr=1e-4`、2 epochs 和最佳
checkpoint 选择，目标是验证清洗训练数据后是否能进一步降低重复生成，并改善
单轮与多轮角色扮演质量。

需要注意：`run_manifest.json` 记录 `data_dir=processed_clean`，但 train/val/test
hash 与当前 `processed/` 一致，和当前本地 `processed_clean/cleaning_manifest.json`
不一致。因此本次结果应写成“清洗目录运行记录”，不能作为严格的清洗单变量因果
实验。

## 2. 核心结论

`train_5` 取得了当前最高的单轮综合分和最低的 LoRA 重复率，但仍没有解决多轮
退化：

- 单轮综合分：`Base + card 2.722 -> LoRA + card 2.989`
- 单轮胜率：LoRA `55.0%`，Base + card `45.0%`
- 多轮综合分：`Base + card 3.523 -> LoRA + card 2.780`
- 多轮胜率：LoRA `25.0%`，Base + card `75.0%`
- 重复率：Base + card `2.9%`，LoRA `17.8%`
- PPL：Base + card `94.725`，LoRA `10.760`

单轮提升的 95% CI 为 `[-0.039, 0.580]`，仍包含 0；多轮差值的 95% CI 为
`[-1.080, -0.378]`，明确低于 0。

## 4. 评估解释

正面结果：

- LoRA 单轮身份、风格、相关性、自然度、沉浸感均高于 `Base + card`。
- 拒答率从 `Base + card` 的 4.0% 降至 1.0%。
- 重复率较 `train_4` 略降，从 18.1% 到 17.8%。

负面结果：

- 多轮 identity 从 `Base + card` 的 3.650 降至 2.600。
- 多轮 style 和 immersion 均只有 2.200，低于 `Base + card` 的 3.350。
- 多轮综合差值为 -0.743，比 `train_4` 的 -0.485 更差。

这说明单条样本的回复质量和多轮保持能力没有同步提升。当前 SFT 仍更像是在学习
短回复分布，而不是学习“基于历史继续扮演同一角色”的策略。

## 5. 后续改进

下一步优先运行 `train_6_clean_windows.yaml`：

- 每条对话不只生成一个最近后缀样本；
- 为前期、中期、后期 assistant turn 各构造窗口；
- 每个窗口只监督目标 assistant 回复；
- 保留角色卡和目标回复前的最近上下文。

预期它比单个 conversation suffix 更贴近多轮评估任务。如果 `train_6` 仍然多轮
落后，应再考虑降低学习率、增加反重复过滤或引入偏好优化。
